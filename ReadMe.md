## WordPress Theme Development folder
For WordPress theme development we need to have a installed WordPress Project.

For theme development we need to go, `WordPress --> wp-content --> themes` folder, because in here we create a sub-folder for our new theme and do all works inside that sub-folder. 


## WordPress development environment
For WordPress theme and plugin development, we need to have a development environment, for this we use, 

* Laragon &
* VS code editor


## Important VS code extensions for wp development
* WordPress Snippets


## Design For theme development
For theme development, we need to have a design template in our hand to convert it into WordPress theme. It can be a Figma design.

## Theme Unit Test
To test a WordPress theme if it works perfectly, we can check offical [Theme Unit Test](https://developer.wordpress.org/themes/advanced-topics/testing/). Here we cab get test data to Import for posts, pages, comments, custom fields, categories, and tags.
